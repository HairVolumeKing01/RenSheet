# 相册排表当前开发规则

本文件记录 2026-09-28 用户确认的页面行为；v2.8 随产品页面、README 与首页公告一并提交。

- 一次导入多张清晰截图，按文件名自然排序；用户可调整，并必须确认顺序后才能识别。建议分图，不强制拒绝长图。
- 相邻截图边界的相同评论提示疑似重叠，须确认保留或显式忽略；不自动删除真实重复留言。
- 图片按 SHA-256 内容指纹防重，同一图片换文件名仍视为重复。已识别图片补选仅恢复原图对照，不追加评论。
- 一次按确认顺序识别整个队列；已成功的图片不重复处理，失败图片可重试。日期只作辅助信息，缺日期、尾部无日期都不丢弃评论。
- 统一校对 CN、正文与角色归属，保留原图对照；空 CN、空正文、无法确定的数量需要补齐或显式忽略。
- 仅点击 STEP 2 校对区的原图（或在图片聚焦时按回车/空格）打开原图悬浮窗；导入区缩略图只切换原图，不打开悬浮窗。每张图独立开关，同图重复点击只唤起已有窗口，多图可同时查看；支持拖动标题移动、右下角调整窗口大小、图片缩放、适应宽度、收起与关闭，手机同样可操作。窗口不阻挡校对或实时排表，移除图片或重置时关闭对应窗口。
- 输出前选择单领模式或配比模式。单领不填总配数；凹/all 没有上限时必须改为明确数量。
- 配比模式填写正整数总配数，每个角色使用相同限额。表格超过总配数的底部整行置灰，整行所有角色均不计入有效配数，保留最早排列的行。
- 导出或转肾表前，若存在灰行，必须由用户选择删除灰行或保留灰行；取消不导出、不修改评论。保留灰行的 Excel 也呈灰色，但数据仍是标准排表。
- 角色列用左右箭头调整，确认角色归属及刷新都保留人工列顺序。
- STEP 1 提供“重置本次排表”：确认后清空本次图片、评论、模式、配数、单价及校对状态，同时清除新旧草稿；保留已保存的角色对照。识别、读取图片或导出期间禁用重置，刷新不得恢复被重置的数据。
- STEP 3 与悬浮排表共用导出矩阵及排版：第一行仅 A1 品类名，第二行角色，第三行单价，第四行起为序号与 CN 数据；两处均显示单价、列顺序和底部灰行。列移动按钮与数量统计置于表格外，不额外导出统计行。
- 页面采用一次校对、单份实时预览与最终导出的流程；移除顶部“重新开始”，使用说明不出现真实角色例子，文案简短。
- 使用说明、角色对照与单价折叠框采用医用蓝/水色标题栏、清晰边框及展开状态提示；使用说明第 2 步简述原图校对、评论补充或忽略，以及同角色称呼归一后确认对照的操作。
- 使用说明突出本地批量识别与评论格式：角色加正整数数量、角色凹/all；凹/all 只在配比模式补足该角色剩余配数，之后同角色记录不再排入，单领须改成明确数量。排序按确认的图片顺序、图内从上到下的评论顺序，逐角色独立填列，数量占对应格数；日期不参与排序。
- 实时排表悬浮窗默认扩大至桌面最大 860px 宽、640px 高（随视口收窄），移动端最大占 48% 屏高；表格在窗内滚动，保留桌面拖动与大小调整、关闭入口。本次补充记录到 README，不加入首页公告。
- STEP 1 图片卡片支持拖拽排序，桌面参照二调页热度排序交互；手机可拖动手柄，靠近屏幕上下边缘自动滚动，键盘可用左右方向键调整。排序后须重新确认，评论随图片移动且保留图内顺序。
- 先选中评论，再新增一条空评论到其后；新评论沿用所选图片来源并自动选中，图内插入位置在刷新和图片排序后保留，修改内容立即同步两处排表与导出。
- STEP 3 使用肾表页相同的 16 套调色盘与标题、表头、数据行配色。预览、实时表与 Excel 共用样式，灰行始终优先显示灰色。
- 文件名称独立于品类名，默认使用品类名；重命名、主题随草稿恢复，重置时清空。文件名不改变 A1 品类名与标准排表结构，导出与转肾表使用同一文件名。
- 保留本地识别、标准 A1 / 角色 / 单价 / CN 数据结构，以及转入肾表的交接方式。版本提交与推送按用户授权执行。
